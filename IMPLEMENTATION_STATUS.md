# ShieldGuard holati

Dastlabki auditda ish papkasida loyiha fayllari va Git ombori yo‘q edi. Android shabloni o‘rnatilgan Flutter SDK yordamida yaratildi. Paket versiyalari SDK bilan mos keladigan rezolyutsiyadan olindi.

| Modul | Holat | Izoh |
| --- | --- | --- |
| Havola | Faqat lokal heuristik tekshiruv | Domen, asosiy sintaksis, taqlid, qisqartirish va kontekst belgilari |
| Xabar va bot | Faqat lokal heuristik tekshiruv | O‘zbekcha, ruscha va inglizcha iboralar. Shaxsni tasdiqlash mavjud emas |
| Fayl | Qisman ishlaydi | Imzo, SHA-256, APK metama’lumoti va sertifikat, PDF markerlari, PE hamda arxiv chegaralari. To‘liq format validatsiyasi mavjud emas |
| Avtomatik himoya | Android tomonidan cheklangan | Tizim bergan Telegram bildirishnomalari va ikki ruxsat. Qurilma sinovi tafsilotlari test hisobotida |
| Akkaunt qo‘llanmasi | Qisman ishlaydi | Yo‘riqnoma va joriy seansda qo‘lda belgilanadigan ro‘yxat |
| Tarix | To‘liq ishlaydi | Ixtiyoriy SQLite yozuvlari, tur, sana va yuqori xavf filtrlari, tozalash |
| O‘zbekcha interfeys | To‘liq ishlaydi | ARB katalogi, Android resurslari va ochiq/qorong‘i mavzu |
| Onlayn reputatsiya | Tashqi servis talab qiladi | Provayder, litsenziya va integratsiya ushbu yig‘ilishga kiritilmagan |
| Release | Hali ishlab chiqilmagan | Tarqatish imzosi va Play Console bo‘yicha nashr sozlamalari kerak |
