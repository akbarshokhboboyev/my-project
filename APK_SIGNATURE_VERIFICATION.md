# APK imzosi

NativeFileInspector Google apksig 9.1.0 ApkVerifier yordamida max(26, ilova minSdk) dan boshlab imzo yaxlitligini tekshiradi. Natija tasdiqlandi, muvaffaqiyatsiz yoki tekshirilmadi ko‘rinishida qaytadi. Sertifikat SHA-256 qiymatlari apksig verifier natijasidan olinadi; PackageManager manifestni signing flagisiz o‘qiydi. Signing lineage va rasmiy nashriyotchi provenance integratsiyasi hali tugallanmagan.

TrustedDeveloperRegistry alohida typed reference qatlami. Paket, sertifikatlar to‘plami, HTTPS manba va valid signature shartlari bor. Production reference ro‘yxati kiritilmagan. Testdagi fixture-only haqiqiy sertifikat emas. Ushbu registr hali UI verdictga ulanmagan.

Imzo tekshiruvining qo‘llab-quvvatlanmaydigan sxemasi uchun alohida status ajratilmagan. Haqiqiy zararli namunalar bajarilmadi.
